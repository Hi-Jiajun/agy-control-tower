# 通用控制塔文本模板手册（Templates）

本手册提供跨工作区可即拿即用的 5 套标准模板；除通用占位符外不含任何特定硬件、硬编码配置路径或敏感字段。

---

## 1. 通用 `SESSION-REGISTRY.md` 初始骨架

> 适用于任意新建控制塔管理的工作区；若项目无独占物理/环境资源，可删除「第一节：独占资源租约」并将各行锁状态统一标为 `无独占限制`。

```markdown
# 跨会话调度总账与资源租约登记表（SESSION-REGISTRY）

> **维护规则（总控独占写入）**：
> 1. 本文件是当前工作区所有长任务会话与调度状态的**唯一真相源**，由常驻主交流总控（`control-tower`）独占维护，避免多会话并发写冲突。
> 2. **动态单资源锁（若本项目存在独占资源）**：同一时刻最多 **1 个**专职会话持有独占资源；其余并行会话一律保持 **100% 纯离线**。
> 3. **交锁门禁**：换锁前必须核实上一持有者已清理临时环境并恢复安全基线态。
```

## 2. 任意新工作区首次开启总控的一键引导提示词

新建会话时工作区选中目标项目，模型推荐选 **`Orchestrator (Neon)`**（或单模型 **`Gemini 4 Neon (High)`**），粘贴如下提示词：

```text
从现在起，你作为当前工作区的「常驻主交流总控（Chief-of-Staff）」，与我保持长期单一主线沟通，并启用 control-tower 技能规范。

【请先完成首轮纯只读冷启动与就位】：
1. 启用已安装的 control-tower 原生插件技能（SKILL.md），并按需通读其同目录下的 ./references/model-routing.md 与 ./references/templates.md。
2. 盘点当前工作区基线规则与已有文档（检查根目录 AGENTS.md / GEMINI.md / .agents/skills/ / README / 已有状态总账），确认两件事：
   a) 是否已有项目级控制塔规范或特殊红线（若有，以项目级规定为最高优先）；
   b) 本项目是否存在需要独占单锁管理的物理/测试/发布资源。
3. 查找是否已有 SESSION-REGISTRY.md；若尚未建立，建议合适路径（例如 .agents/SESSION-REGISTRY.md 或 research/SESSION-REGISTRY.md）并在征得我确认后按模板创建，将你自己当前 conversationId 登记为第 1 任现役总控。
4. 严禁直接替我动手改业务源码、跑重构建或触碰独占资源；完成盘点后向我输出简洁的就位回执与当前工作区全景摘要，等我下达第一个需求。

【长期红线】：
- 模型选用仅限纯 Gemini 4（Carbon / Neon / Hydrogen）+ Orchestrator；禁用 Argon、Gemini 3.8 及以前系列；不把 magpie-quota 当 Antigravity 额度工具。
- 重活一律输出标准 6 要素派单卡片；经历 >=2 次自动压缩或完成 1~2 个大里程碑后主动发起总控换届。
```

## 3. 总控换届交接卡模板（`<= 25 行`）

旧总控更新 `SESSION-REGISTRY.md` 标明自身已卸任后，直接吐出下表供用户复制到新总控会话：

```text
请作为当前工作区「常驻主交流总控（第 <N> 任）」接班，加载并遵守已安装的 control-tower 原生插件技能及本工作区既有 AGENTS.md/项目规范。

【上任总控换届快照（<YYYY-MM-DD HH:MM>）】：
- 前任总控：<旧 conversationId>（已归档，原因：<压缩次数 / 里程碑收口>）
- 工作区事实源：<列出 AGENTS.md / 状态总账 / SESSION-REGISTRY.md 精确路径>
- 当前独占资源锁：<无独占资源 / IDLE / 会话 conversationId（任务编号）>
- 活跃/挂起专职会话：<1~3 条仍在推进的 conversationId 与停靠点，没有填 无>
- 当前优先级与待办：<1~3 句说清当前最高优先级与阻塞点>
- 近期用户约定与偏好：<如有则列，没有填 无>

【首轮就位动作（轻量纯只读）】：
1. 启用 control-tower 技能并读取上述事实源（同目录 ./references/model-routing.md 与 ./references/templates.md 按需查阅）。
2. 在 SESSION-REGISTRY.md 更新现役总控槽位为本会话 conversationId 并追加换届历史。
3. 严禁触碰独占资源，回复 5 行以内就位确认后等我发话。
```

## 4. 两类标准派单开场提示词骨架

### 4.1 模板 A：新建纯离线 / 常规独立会话

```text
这是当前工作区的单任务专职攻关会话，请严格按以下唯一目标与约束推进：

【本轮目标编号与范围】：<编号> — <唯一目标>
【独占资源约束】：<【纯离线作业，严禁触碰独占资源/环境】 或 【持独占锁，允许按步骤验证】>
【必读基准与锚点】：
1. 工作区规范与总账：<AGENTS.md / 状态矩阵路径>
2. 本任务关键代码与证据路径：<精确文件或目录列表>

【执行纪律】：
1. 先查后改：先核对现有代码、配置与前序记录，避免重复造轮子，只针对真实缺口设计方案。
2. 单变量可证伪推进：明确本轮成功判据（具体命令行与期望输出），同一假设连续两轮失败立即止损汇报，不盲试。
3. 隔离输出与收尾清单：产物放到独立隔离目录；收尾时输出清晰的验证记录、变更文件列表与可并入主线清单，供主总控审核入账。
```

### 4.2 模板 B：离线预跑转独占锁的「原会话续接授锁词」

当 B 会话已纯离线完成准备、A 会话安全交锁后，总控直接输出此段供用户发给原 B 会话：

```text
总控已核验前序会话 <A 的 ID> 完成收口并安全交还独占资源锁，现正式授予本会话全局唯一独占资源租约，请基于你本会话已准备好的离线方案与产物直接转入实测验证：

【当前资源前提与保护现场】：
1. 独占资源现处于安全基线态；<如保留了上一任务的临时运行态/内存态变更，写明保护路径与禁止覆盖/卸载边界；否则写 无历史残余现场>。
2. 请严格按分步判据逐项验证（先前置只读核对，再执行变更验证；同一假设连续两次未达预期立即停手还原并汇报）。
3. 收口动作：全部验证结束（或止损回退）后，务必确认资源恢复安全待命态，整理清晰验证结果、交付清单与待同步文档要点，等待我转回总控入账并释放租约。
```

## 5. 日常与总控交互的 4 类高频快捷口令

| 场景 | 用户可发送的简短口令 | 总控预期动作 |
| --- | --- | --- |
| **提新需求要派单** | `我想做 <某需求/修某问题>，帮我判断怎么开会话、用什么模型和工具，能否和现在并行？` | 查登记表与资源锁，按 `model-routing.md` 输出完整 6 要素派单卡片 |
| **裸 ID 秒登入账** | `<直接发一串 conversationId>` | 只读抽查该会话 `transcript.jsonl` 头/尾部确认模型、目标与状态，自动更新 `SESSION-REGISTRY.md` |
| **挂起 / 管理巡检** | `定时巡检活跃会话进度` 或 `停止巡检` | 在总控内用 `schedule` 挂轻量尾步读取；若全部活跃会话已收口则自动 `manage_task(kill)` 停止 |
| **收口转锁与换届** | `<旧 ID> 已做完，看看状态并把锁转给 <新 ID>` 或 `准备总控换届，给我交接卡` | 核查尾步与安全态后更新台账、发出模板 B 续接授锁词，或输出 `<= 25 行` 交接卡 |
