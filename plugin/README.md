# control-tower

面向 **Google Antigravity** 的通用常驻主交流总控（Chief-of-Staff）原生插件，用于在任意工作区建立轻量、常驻、不亲自下场写重代码的调度主线，统一负责需求拆分、新建与续接会话裁决、独占资源单锁调度、纯 Gemini 4 与 Orchestrator 分层模型路由、裸 ID 秒登入账与总控换届。

## 内置组件

- **总控规程技能（`skills/control-tower/`）**：按需渐进式加载，包含核心调度规程、`model-routing.md` 路由手册与 5 套即用中文模板。
- **可读写 Aux Pane 总控看板（`sidecars/tower/`）**：支持工作区切换、`SESSION-REGISTRY.md` 第 1~5 节全结构化操作（独占租约锁管理、现役总控登记与换届历史记录、裸 ID 尾步探针一键入账、活跃会话归档至里程碑、待调度队列增删、Markdown 在线编辑器），以及向现役总控一键投递裸 ID 与模板复制。
- **总控定向轻量感知 Hooks（`hooks.json` + `scripts/ct-hook.mjs`）**：仅在当前会话登记为工作区现役总控时激活，普通专职会话静音直通且不写入状态文件；支持单裸 ID 与短口令内多会话 ID 尾步速查，以及现役总控 `>= 2` 次上下文压缩防刷屏换届提醒。

## 常用总控口令

1. **冷启动或接管工作区**：选择推荐提示词或发送「启用 `control-tower` 总控规程，执行纯只读盘点并初始化 `SESSION-REGISTRY.md`」。
2. **新需求派单裁决**：发送「我想做 `<某需求>`，帮我判断新建还是续接、选什么模型和工具，能否和当前会话并行？」。
3. **裸 ID 秒登入账**：直接发送一串 `conversationId`（或 8+ 位十六进制前缀），或发送「`<旧ID>` 已做完，看看状态并把锁转给 `<新ID>`」。
4. **总控换届交接**：收到换届提醒后发送「准备总控换届，同步台账并输出交接卡」。
