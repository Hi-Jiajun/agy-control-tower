# control-tower

面向 **Google Antigravity** 的通用常驻主交流总控（Chief-of-Staff）原生插件，用于在任意工作区建立轻量、常驻、不亲自下场写重代码的调度主线，统一负责需求拆分、隐藏面优先自适应派遣（原生 `swarm` / `invoke_subagent` / `run_workflow` 与白名单 `agentapi` 直派）、冷热解耦焦点防打扰代决策、四象限隔离协作、三层长期项目路线图、独占资源单锁控制与双证总控换届。

## 内置组件

- **总控规程技能（`skills/control-tower/`）**：按需渐进式加载，包含核心调度规程（隐藏面优先白名单、冷热解耦焦点防打扰、四象限隔离协作、三层长期项目路线图、智能双触发 `/learn` 审批闭环）、`model-routing.md` 路由手册（全最高思考舒适区 + 新版 `Orchestrator` 主力 + `Swarm` 显式配模）与即用中文模板；支持全局/工作区级在线覆盖。
- **可读写 Aux Pane 总控看板（`sidecars/tower/`）**：模块化前后端架构、零依赖 `fs.watch` + SSE 实时流推送、跨工作区全局概览抽屉与内联二次确认微交互；支持四执行面统一任务导航（含原生 Swarm 隔离档位徽章与一键休眠回收）、一键发送 `/learn` 学习指令、单真源 `P0/P1/P2` 优先级收件箱与零 Token 哨兵、三层长期路线图交互依赖树（一键交总控隐藏面派单、填入白名单直派与 `.agents/handoffs/` 契约预览）、`SESSION-REGISTRY.md` 第 1~5 节全结构化运维与原生内联归档表单、黑匣子飞行诊断日志视图，以及严格物理隔离的三层设置中心（含 `autoLearnMode`）。
- **四事件定向感知 Hooks（`hooks.json` + `scripts/ct-hook.mjs`）**：覆盖 `SessionStart`（双角色注入与路线图进度速览）、`PreInvocation`（裸/多 ID 速查、代决策指引、前台焦点态登记、节流兜底哨兵、`[CT_REPORT:DONE]` 路线图联动、双触发 `/learn` 纠偏/收口检查点、弹性换届与静默版本同步）、`PreToolUse`（合法换届双证自动放行与非总控台账防误改保护）与 `Stop`（总控焦点锁无条件释放、焦点防打扰暂缓与纯零 Token 双轨回执）。

## 常用总控口令

1. **冷启动或接管工作区**：选择推荐提示词或发送「启用 `control-tower` 总控规程，执行纯只读盘点并初始化 `SESSION-REGISTRY.md`」。
2. **新需求派遣**：发送「我想做 `<某需求>`，帮我安排会话」，总控将通过 `ask_question` 推荐最佳派遣通道与模型，并在确认后直接拉起并入账。
3. **裸 ID 秒登入账**：直接发送一串 `conversationId`（或 8+ 位十六进制前缀），或发送「`<旧ID>` 已做完，把锁转给 `<新ID>`」。
4. **总控弹性换届**：压缩次数达到设定阈值（默认 `5` 次）时可选择一键接班换届，或标记本会话忽略提醒。
