# Control Tower (`control-tower`)

面向 **Google Antigravity** 的通用常驻主交流总控（Chief-of-Staff）原生插件。它在任意工作区建立一条**轻量、常驻、不亲自啃大代码与大日志**的主对话指挥线，统一统筹需求拆解、隐藏执行面调度（原生 `swarm` / `invoke_subagent` / `run_workflow`）、冷热解耦零 Token 后台哨兵、独占资源单锁、三层长期路线图 DAG 与实时 SSE 可视化面板。

> **零全局污染承诺**：本插件不包含任何全局 Always-On 规则（`components.rules === 0`），对未启用控制塔的普通会话保持 **100% 静音零干扰**；同时支持 `PLUGIN_DATA` 零侵入托管模式，对业务 Git 仓库零新增文件。

## Aux Pane 控制面板六大视图

在 Antigravity 右侧辅助栏打开 **Control Tower**，即可通过双行紧凑顶栏与实时数字角标一屏掌控全局：

| 页签 | 核心能力 |
| --- | --- |
| **总览** | 现役总控健康态（一键跳转、发送 `/learn`、登记/换届、压缩超限一键接班）、独占单锁租约（`IDLE` 自动静默收敛 / 持锁一键释放）、零 Token 哨兵与 `P0/P1/P2` 优先级收件箱 |
| **执行面** | 四执行面统一态势网格（Swarm / Subagent / Workflow / 顶层会话）、活跃原生 Swarm 成员与隔离档位监测（含一键回收休眠成员）、白名单受控直派与裸 ID 尾步探针 |
| **路线图** | 按需启用的 `L1 ROADMAP.md` 战略北极星与 `L2 roadmap.json` 分支依赖树：自动计算 `READY` 就绪分支、拦截循环依赖、预警并行文件所有权冲突、内联预览 `.agents/handoffs/` 契约并一键交总控隐藏面派单 |
| **队列** | `SESSION-REGISTRY.md` 待调度任务队列可视化增删改与分层模型路线预设选择 |
| **台账** | 6 套即用调度与换届提示词模板一键复制，以及带 SHA-256 乐观锁防覆盖保护的原始台账在线编辑器 |
| **设置** | 严格物理隔离的「插件运行 / 全局策略 / 当前工作区」三层配置、原生分组模型选择器（支持动态同步自定义白名单）、路由与模板文档在线覆盖及脱敏黑匣子飞行诊断日志 |

## 三大核心架构组件

- **按需总控技能（`skills/control-tower/`）**：渐进式加载核心调度规程、`model-routing.md` 实证舒适区路由手册（`L0` 单模型 `Gemini 4 Neon (XHigh)` 零切层稳态总控 + `L2/L4/Swarm` 新版 `Orchestrator (Neon Extra High)` 高速执行 + `L3` `Orchestrator (Carbon)` 攻坚）与跨工作区标准模板。
- **实时 SSE 看板服务（`sidecars/tower/`）**：纯零第三方依赖本地环回服务，基于 `fs.watch` + SSE 推送与 `stateSig` 零载荷静默短路，内置恒定时间鉴权、防 DNS Rebinding 及跨站请求拦截。
- **四事件生命周期 Hooks（`hooks.json` + `scripts/ct-hook.mjs`）**：覆盖 `SessionStart`（双角色边界与路线图进度速览）、`PreInvocation`（裸/多 ID 速查、焦点防打扰登记、节流哨兵、`[CT_REPORT:DONE]` 路线图联动与智能双触发 `/learn` 检查点）、`PreToolUse`（跨内置与 MCP 工具的台账写保护及双证换届放行）与 `Stop`（焦点锁无条件释放与纯零 Token 双轨回执）。

## 常用交互口令

1. **冷启动入驻**：在面板首次引导页选择「工作区标准模式」或「零侵入托管模式」一键初始化，或向新会话发送推荐提示词完成纯只读盘点与总控登记。
2. **隐藏面优先派单**：直接描述需求（如「帮我拆解并并行推进 `<某功能>`」），总控将通过 `ask_question` 推荐最佳隐藏执行面与舒适区模型配比。
3. **裸 ID 秒登与转锁**：直接发送会话 `conversationId`（或 8 位以上前缀）自动解析尾步遥测，或发送「`<旧ID>` 已收口，把独占锁转给 `<新ID>`」。
4. **弹性无损换届**：累计压缩达阈值（默认 `5` 次）时，可在面板顶部横幅点击「一键接班」自动预授权拉起新总控，或点击「本会话忽略」继续推进。
