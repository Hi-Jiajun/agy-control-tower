# control-tower

面向 **Google Antigravity** 的通用常驻主交流总控（Chief-of-Staff）原生插件，用于在任意工作区建立轻量、常驻、不亲自下场写重代码的调度主线，统一负责需求拆分、环境自适应派遣（原生 `swarm` / `agentapi` 受控直派 / 手动斜杠兜底）、跨会话双向汇报代决策、独占资源单锁控制与弹性总控换届。

## 内置组件

- **总控规程技能（`skills/control-tower/`）**：按需渐进式加载，包含核心调度规程、`model-routing.md` 路由手册与即用中文模板；支持全局/工作区级在线覆盖。
- **可读写 Aux Pane 总控看板（`sidecars/tower/`）**：支持实时无感监测（同步聚合独立专职会话与原生 `swarm` 集群）、按路由护栏校验的一键直派新会话、`SESSION-REGISTRY.md` 第 1~5 节全结构化运维（支持 `PLUGIN_DATA` 零侵入托管台账与关闭独占资源锁），以及严格物理隔离的「插件 / 全局 / 当前工作区」三层设置中心。
- **四事件定向感知 Hooks（`hooks.json` + `scripts/ct-hook.mjs`）**：覆盖 `SessionStart`（现役总控与已入账专职会话双角色注入）、`PreInvocation`（裸/多 ID 速查、代决策指引与弹性换届提醒）、`PreToolUse`（防非总控误改台账保护）与 `Stop`（专职会话漏报阶段收口自动回执兜底）。

## 常用总控口令

1. **冷启动或接管工作区**：选择推荐提示词或发送「启用 `control-tower` 总控规程，执行纯只读盘点并初始化 `SESSION-REGISTRY.md`」。
2. **新需求派遣**：发送「我想做 `<某需求>`，帮我安排会话」，总控将通过 `ask_question` 推荐最佳派遣通道与模型，并在确认后直接拉起并入账。
3. **裸 ID 秒登入账**：直接发送一串 `conversationId`（或 8+ 位十六进制前缀），或发送「`<旧ID>` 已做完，把锁转给 `<新ID>`」。
4. **总控弹性换届**：压缩次数达到设定阈值（默认 `5` 次）时可选择一键接班换届，或标记本会话忽略提醒。
